# SW YT Downloader (SW-YTify)

SW YT Downloader is a premium, high-performance web application designed to fetch and download YouTube videos and full playlists effortlessly. It offers a sleek, modern UI with features that put user experience and speed first.

## ✨ Features
- **Single Video & Playlist Downloads**: Extract metadata and download single videos or massive playlists with just one click.
- **Multiple Formats**: Choose between high-quality MP4 (Video) or MP3 (Audio).
- **Quality Selection**: Pick exactly what resolution or bitrate you need, from standard all the way up to the best available (1080p+ video, 320kbps audio).
- **Real-time Progress Tracking**: Powered by Server-Sent Events (SSE), you get live progress bars, download speeds, and ETA right on your screen.
- **Premium UI/UX**: Built with a stunning dark-mode-first aesthetic, skeleton loading animations, responsive grid layouts, and smooth transitions.
- **Mobile Responsive**: Fully optimized layout that works flawlessly on phones, tablets, and desktop computers.

## 🛠️ Technology Stack
- **Backend**: Node.js, Express.js
- **Frontend**: EJS Templating, Vanilla JS, CSS3 (Modern Grid & Flexbox)
- **Core Download Engine**: `youtube-dl-exec`, `ytpl`, and `ffmpeg-static`

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/SW-YONTO/SW-YT.git
   cd SW-YT
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
